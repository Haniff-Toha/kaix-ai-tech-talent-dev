# Kaix - AI-Powered Tech Talent Companion

Kaix is a next-generation platform designed to empower tech talent through AI-driven learning paths, performance analytics, and personalized mentorship. It helps developers track their progress, maintain learning streaks, and optimize their skill development journey.

## Repository Structure

This repository uses a multi-branch strategy to organize its components:

- **`main` (this branch)**: Contains project documentation, design decks, and overall configuration.
- **`fe` branch**: Contains the frontend application (React, TypeScript, Vite, Tailwind CSS).
- **`be` branch**: Contains the backend services (Python, FastAPI/PostgreSQL).

## Key Features

- **AI Career Pathing**: Personalized roadmap generation based on skill gaps.
- **Learning Streaks**: Gamified experience to keep you motivated.
- **Performance Analytics**: Detailed insights into learning progress and coding habits.
- **Resource Aggregator**: Curated list of best resources for your specific path.
